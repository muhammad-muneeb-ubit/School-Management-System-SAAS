# School-Management-System-SAAS

MERN stack starter repository with separate client and server applications.

## Project Structure

- `client/` - React app (Vite starter)
- `server/` - Node.js + Express starter API

## Setup

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
cp .env.example .env
npm run dev
```
